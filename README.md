# ליווי מכירות — דף נחיתה

דף נחיתה עצמאי בעברית (RTL) עבור שירות ליווי אישי במכרזים ובהגרלות רמ"י
לרכישת קרקע/בית.

הפרויקט נבנה כ-**HTML, CSS ו-JavaScript רגילים בלבד** (ללא React/Vue/Angular,
ללא npm וללא תהליך build), במטרה שיהיה קל להעביר ולהטמיע בעתיד כעמוד נוסף
בתוך האתר הקיים:

https://droratid.netlify.app/

לדוגמה בנתיב: `droratid.netlify.app/sales-support`

**חשוב:** הפרויקט הזה **לא** נוגע, לא מתחבר ולא מבצע Deploy לאתר הקיים.
זהו עמוד עצמאי ונייד, מוכן להעברה למפתח/ת אחר/ת שיבצע/תבצע את ההטמעה בפועל.

---

## מבנה הקבצים

```
sales-support-landing-page/
│
├── index.html          כל מבנה העמוד (HTML סמנטי, dir="rtl", lang="he")
├── style.css            כל העיצוב, כולל משתני צבע ו-Media Queries רספונסיביים
├── script.js             כל האינטראקציות (תפריט מובייל, אקורדיון, טופס)
├── README.md
│
└── images/
    ├── hero/            תמונת ה-Hero (זוג/משפחה על מגרש)
    ├── sections/         תמונות תוכן (ילדים בגינה, מילואים...)
    ├── testimonials/     אווטר placeholder להמלצות לקוחות
    └── icons/            (שמור לשימוש עתידי — כרגע כל האייקונים הם SVG מוטמע ב-HTML)
```

כל ה-classes ב-CSS וב-HTML מתחילים ב-prefix ‎`sales-`‎ (למשל ‎`sales-hero`‎,
‎`sales-card`‎, ‎`sales-btn`‎) כדי למזער התנגשויות עם ה-CSS של האתר הקיים בעת
ההטמעה. כל הנתיבים לתמונות, ל-CSS ול-JS הם **יחסיים** (relative paths) —
אין נתיבים מקומיים למחשב.

## סדר חלקי העמוד

העמוד בנוי לפי 9 חלקים, בסדר הבא (כל אחד תואם ל-`id` בתוך `index.html`):

1. `sales-hero` — Hero
2. `sales-audience` — למי השירות מתאים
3. `sales-reservists` — אזור מיוחד למשרתי מילואים
4. `sales-why-us` — למה לבחור בנו (6 יתרונות)
5. `sales-how` — איך זה עובד (Timeline בן 4 שלבים)
6. `sales-tracks` — המסלולים (3 כרטיסי מחיר)
7. `sales-testimonials` — לקוחות מספרים (3 כרטיסים)
8. `sales-faq` — שאלות נפוצות
9. `sales-lead-form` — סיום: CTA + טופס

> **הערה:** בגרסאות קודמות היו גם ה-sections הבאים, שהוסרו לפי בקשה
> מפורשת ואינם קיימים יותר בקוד: "הבעיה" (`sales-problem`, כרטיסי שאלות
> עם אייקון "?"), "דמיינו את הרגע הזה" (`sales-emotion`, כולל תמונת
> placeholder), ו-"אתם מביאים את החלום. אנחנו מטפלים בדרך" (`sales-approach`,
> 4 כרטיסי שלבים).

## איך פותחים את הפרויקט מקומית

אין צורך בהתקנה, בשרת או בתהליך build. שתי אפשרויות:

1. **הכי פשוט:** לחיצה כפולה על `index.html` — ייפתח ישירות בדפדפן.
2. **מומלץ לבדיקות מדויקות יותר** (למשל כדי לוודא שנתיבי תמונות עובדים
   בדיוק כמו בשרת אמיתי): להריץ שרת סטטי קטן מתוך תיקיית הפרויקט, לדוגמה
   עם Node.js מותקן:

   ```
   npx http-server -p 8080
   ```

   ואז לפתוח בדפדפן: `http://localhost:8080`

## מה כבר עובד

- כל 9 חלקי דף הנחיתה בנויים ומעוצבים לפי המפרט המעודכן, בדיוק לפי
  הסדר והתוכן שנמסרו.
- תפריט מובייל (המבורגר), Smooth Scroll לכפתורי CTA, ואקורדיון שאלות
  נפוצות — ב-JavaScript רגיל, ללא ספריות חיצוניות.
- טופס הלידים כולל Validation בסיסי בצד לקוח (שם וטלפון חובה, אימייל
  בפורמט תקין אם הוזן) — **אך אינו שולח מידע לשום שרת** (ראו סעיף חיבור
  הטופס למטה).
- נבדק ידנית ברוחבי מסך של Desktop, Tablet ו-Mobile, וללא שגיאות
  Console.

## איפה מחברים את הטופס (Lead Form)

הטופס נמצא ב-`index.html` בתוך `<section id="sales-lead-form">`, והלוגיקה
שלו ב-`script.js` בפונקציה `initLeadForm`. חיפוש המחרוזת `TODO` בקובץ
`script.js` יוביל ישירות למקום המדויק. כרגע, בסיום Validation תקין, הטופס
רק מציג הודעת הצלחה מקומית ומתאפס — **אין שום קריאת רשת בפועל**.

כדי לחבר לשרת/CRM אמיתי, יש להוסיף בתוך ה-`submit` handler (בתוך
`initLeadForm`) קריאת `fetch` (או אינטגרציה מתאימה אחרת) שתשלח את השדות
`name`, `phone`, `email`.

## הערות למפתח/ת שיבצע/תבצע את ההטמעה באתר הקיים

- כל ה-CSS מבודד תחת prefix ‎`sales-`‎ והריסטים מוגבלים לאזורי
  `.sales-header`, `.sales-main` ו-`.sales-footer` בלבד — לא אמור להשפיע
  על שאר האתר.
- צבעי המותג מרוכזים במשתני CSS יחידים בראש `style.css` (בתוך `:root`),
  כדי שיהיה קל להתאים אותם לצבעי האתר הקיים.
- כל ה-JavaScript עטוף ב-IIFE יחיד (`(function () { ... })()`) כדי לא
  להדליף משתנים גלובליים.
- מקום מוכן להוספת Google Analytics / Meta Pixel מסומן בהערה בראש
  `index.html` — לא הוטמע קוד מעקב בפועל.
- אין נתיבים קשיחים ל-`localhost` ואין תלות ב-root של דומיין — כל הנתיבים
  יחסיים לתיקיית הפרויקט.
